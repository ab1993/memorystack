# Contributing to MemoryStack 🧠

We love your help! To keep the project stable, please follow these steps:

1. **Fork** the repo and create your branch from `develop`.
2. Ensure your code follows the **Professional Logging** format.
3. Keep logic in the **Service Layer** (NotificationManager, SprintEngine).
4. Open a **Pull Request** against the `develop` branch.
5. Wait for a maintainer to review and merge!

### Branching Summary
- `main`: Stable releases.
- `develop`: Ongoing development.
- `feature`: Experimental features.
- `bugfix`: Bug fixes.
